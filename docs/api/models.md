# `tenet.models`

The standard local sites and the named Hamiltonians on them. See the guide,
[Building a Hamiltonian](../guide/hamiltonians.md).

| function | what it builds |
|---|---|
| [`heisenberg`][tenet.models.heisenberg] | the XXX chain, `U1` or `SU2` |
| [`xxz`][tenet.models.xxz] | the anisotropic chain, `U1` |
| [`transverse_field_ising`][tenet.models.transverse_field_ising] | the Ising chain in a field, `Z2` |
| [`hubbard`][tenet.models.hubbard] | the spinful Hubbard chain, `fZ2` |
| [`spinless_tv`][tenet.models.spinless_tv] | spinless fermions with nearest-neighbour repulsion, `fZ2` |
| [`sun_heisenberg`][tenet.models.sun_heisenberg] | the SU($N$) fundamental exchange chain |
| [`sun_exchange`][tenet.models.sun_exchange] | that chain's bond term, on its own |

::: tenet.models
